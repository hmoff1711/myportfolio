Selected work

Infrastructure case studies

Sanitised examples showing the problem boundary, technical method, controlled decision and verified operational result.

01 · Storage & access control

OneFS SMB access for protected media folders

OneFS 9.x · SMB · ACLs · Protocol Audit

Challenge

Provide read, copy and create access in protected folders without allowing users to modify, delete, rename or change permissions, while keeping other folders fully writable.

Technical work

  • Inspected recursive ownership and ACL data with isi get -DD.
  • Correlated SMB activity through isi_audit_viewer protocol-audit records.
  • Normalized owner, group and inherited ACLs through OneFS PermissionRepair.

Outcome

Existing objects and tested restricted, full-access and administrative paths matched the intended model. Newly created files continued through the documented owner-repair control while native ownership behavior remained under evaluation.

02 · Linux file transfer

ProFTPD SFTP hardening and throughput diagnosis

Ubuntu 24.04 · ProFTPD / mod_sftp · iperf3

Challenge

Daytime SFTP throughput fell to roughly 1.5–3 Mbit/s but reached 90–97 Mbit/s in the evening. The task was to distinguish service configuration from network-path behavior.

Technical work

  • Validated host keys, chroot boundaries, setgid directories, permissions and Umask 007.
  • Disabled the OpenSSH SFTP subsystem so ProFTPD handled SFTP exclusively.
  • Compared transfer ports, time windows, iperf3 throughput and RDP behavior.

Outcome

Authentication, uploads and chroot isolation passed validation. Matching daytime degradation in iperf3 and RDP moved the next investigation step to the network path, QoS and provider track.

03 · Endpoint management

Remote Access Plus HTTPS hardening and GPO pilot

Active Directory · HTTPS/TLS · GPO · SYSVOL

Challenge

Prepare a secure management path and verify the deployment controls required before expanding an endpoint-agent rollout beyond the pilot computer.

Technical work

  • Moved web administration to HTTPS 443 and closed the previous management port.
  • Verified certificate trust from a domain workstation.
  • Confirmed startup-GPO targeting and package availability in SYSVOL.

Outcome

HTTPS, certificate trust and pilot GPO controls passed validation. Wider deployment stayed behind an intentional quality gate until the vendor setup.bat met unattended-install requirements.

Operational incident notes

Focused fault isolation

Windows · SMB · Credential Manager

Credential state isolated from storage permissions

Get-SmbConnection exposed the account actually used by the SMB client. Removing only the matching cmdkey target restored the credential prompt and separated the incident from OneFS access controls.

HP MFP · Microsoft 365 · SMTP

Scan-to-email traced to DNS resolution

Comparison of two identical HP LaserJet Enterprise MFP M528 devices showed that the affected device had no DNS server configured. Restoring hostname resolution returned mail delivery to its separate validation step without misattributing the issue to Microsoft 365 authentication.
